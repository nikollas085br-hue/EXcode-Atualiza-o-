## ✨ O que o EXcode faz

- 📷 **Corrige provas com a câmera**, sem precisar de nada especial
- 🧑‍🏫 **Organiza turmas, alunos e notas**
- 📋 **Gera a chamada em PDF**
- 💾 **Faz backup** dos seus dados
- 🌙 **Modo Black**: preto de verdade, com detalhes em laranja

<br>

## 📲 Como instalar

1. Toque no botão **Baixar para Android** acima.
2. Abra o arquivo baixado.
3. Se o Android pedir, permita a instalação e pronto!

> 💡 Abra esta página pelo **Chrome** para o download funcionar direitinho.

<br>

## 🔄 Atualizações automáticas

Quando sai uma versão nova, o próprio app avisa.
É só tocar em **Atualizar agora**, sem perder nada: **seus dados continuam no aparelho**.
